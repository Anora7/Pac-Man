# Prompt Writing Guidelines

Good prompts should:

- Focus on one feature.
- Define a clear objective.
- List affected files.
- Define constraints.
- Specify expected deliverables.
- Require documentation updates.
- End with a completion summary.

Avoid prompts that request multiple unrelated features simultaneously.

# Lessons Learned

Use this section to capture insights about prompt effectiveness.

Examples:

- Smaller prompts produced cleaner implementations.
- Planning before coding reduced architectural changes.
- Updating documentation after each phase prevented inconsistencies.
- Reviewing generated code before committing reduced rework.
